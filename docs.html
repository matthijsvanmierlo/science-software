Getting Started

ChemCanvas Studio is a zero-backend vector chemistry illustrator. Navigate to the Studio tab to begin drawing.

Keyboard Shortcuts

  • Delete / Backspace: Remove selected object
  • Ctrl + C / Ctrl + V: Copy / Paste (Coming soon)

Features

  • Parametric glassware with adjustable liquid levels.
  • Chemical structure editor using Kekule.js.
  • Direct connection to laboratory sensors via Web Bluetooth.
  • Export high-quality publication-ready SVG, PNG, and PDF files.
